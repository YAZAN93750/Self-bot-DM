## 📖 Overview
A professional, high-performance Discord self-bot designed to handle Direct Messages (DM) with instant, automated responses. Built by YZN Studio for maximum stability and speed.

## ✨ Features
* ⚡ **Instant Response:** Automated replies immediately upon receiving a DM.
* 🔒 **Robust Error Handling:** Built-in protection to ensure continuous bot operation.
* 🎨 **Clean Architecture:** Well-organized, developer-friendly code.
* 👤 **Customizable:** Easily tailor the reply text to fit your needs.
